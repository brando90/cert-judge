-----Description-----
Create a new string in which every character of the input string appears twice consecutively, in the same order.

-----Input-----
- s: String — the input string to transform

-----Output-----
- A String where each character from s is duplicated (e.g., "abc" → "aabbcc").

-----Note-----
- The precondition is True, so all strings are accepted.
- The output length is exactly twice the input length.
