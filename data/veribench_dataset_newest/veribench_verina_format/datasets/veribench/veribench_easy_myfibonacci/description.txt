-----Description-----
Compute the nth Fibonacci number using the standard recursive definition: F(0)=0, F(1)=1, and F(n+2)=F(n)+F(n+1).

-----Input-----
- n: Nat — the index of the Fibonacci number to compute

-----Output-----
- Nat — the nth Fibonacci number

-----Note-----
- The precondition is True, so all natural numbers are accepted inputs.
- An additional imperative implementation exists in the file, but the main function is the recursive `myFibonacci`.
