-----Description-----
Compute the arithmetic mean (average) of an array of floating-point numbers using an imperative loop. If the array is empty, return 0.0.

-----Input-----
- xs: Array Float, the input array of floating-point values

-----Output-----
Returns a Float equal to (sum of all elements) / (number of elements); returns 0.0 when xs is empty.

-----Note-----
The file also defines a functional version over List (mean_func) and proves/specifies properties under a non-empty precondition for lists. Tests use exact equality for simple cases and approximate equality for floating-point-sensitive properties.
