-----Description-----
Reverse each word in the input string while preserving the original word order. Words are delimited by single space characters, and the output words are joined with spaces in the same positions.

-----Input-----
- s: String, the input text containing zero or more words separated by spaces

-----Output-----
A String where each word from the input is individually reversed, with the sequence of words unchanged.

-----Note-----
The implementation splits the string on " ", reverses each substring, and intercalates them back with " ". The precondition is True, so all strings are accepted.
