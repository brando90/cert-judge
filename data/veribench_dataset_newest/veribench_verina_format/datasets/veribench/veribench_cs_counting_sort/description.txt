-----Description-----
Sort a list of natural numbers in nondecreasing (ascending) order using the counting sort algorithm.

-----Input-----
- l: A list of natural numbers (List Nat)

-----Output-----
- Returns a list containing exactly the elements of the input list, sorted in ascending order.

-----Note-----
- If the input list is empty, the result is [].
- The algorithm counts occurrences of each value from 0 up to the maximum value in the list, then reconstructs the sorted list from these counts.
- Precondition is True (all lists are valid inputs).
