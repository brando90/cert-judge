-----Description-----
Remove all space characters (' ') from the input string, preserving the order of all non-space characters.

-----Input-----
- s: String, the input text to process

-----Output-----
A String equal to the input with every space character removed.

-----Note-----
- Only the space character ' ' is removed; other whitespace characters are not specially handled.
- The precondition is True, so all strings are accepted.
