-----Description-----
Searches for a natural number target in a (sorted) list of natural numbers using binary search, returning the index if found.

-----Input-----
- arr: List Nat, the list to search (intended to be sorted in nondecreasing order)
- target: Nat, the value to search for

-----Output-----
Returns an Option Nat: some index if target is found at that index in arr, otherwise none.

-----Note-----
If arr is empty the function returns none. Correctness is intended under the precondition that arr is sorted (List.Sorted (· ≤ ·) arr).
