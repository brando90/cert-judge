-----Description-----
Computes the sum of two natural numbers using standard natural-number addition.

-----Input-----
- a: first natural number addend (Nat)
- b: second natural number addend (Nat)

-----Output-----
- Returns a + b as a natural number (Nat).

-----Note-----
- An infix alias "++" is defined for this function.
- A precondition Pre(a,b) is stated as non-negativity of inputs, which is always satisfied for Nat.
