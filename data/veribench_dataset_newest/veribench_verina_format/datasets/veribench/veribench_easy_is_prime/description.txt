-----Description-----
Determine whether a natural number is prime. Returns true exactly when the input is greater than 1 and has no positive divisors other than 1 and itself.

-----Input-----
- n: Nat — the natural number to test for primality

-----Output-----
- Bool — true if n is prime, false otherwise

-----Note-----
- Uses trial division optimized by checking 2 and 3 first, then testing potential divisors of the form 6k ± 1 up to ⌊sqrt(n)⌋.
- For n ≤ 1 the result is false; for n = 2 or 3 the result is true.
