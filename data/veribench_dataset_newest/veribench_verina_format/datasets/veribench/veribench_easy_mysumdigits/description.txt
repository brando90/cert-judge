-----Description-----
Compute the sum of the decimal digits of a natural number using recursive decomposition into the last digit and the remaining prefix.

-----Input-----
- n: a natural number (Nat)

-----Output-----
- Returns a natural number equal to the sum of all base-10 digits of n.

-----Note-----
- If n is a single digit (< 10), the result is n itself.
- For multi-digit n, it repeatedly adds (n % 10) and continues with (n / 10).
- The stated precondition is True, so all natural numbers are accepted.
