-----Description-----
Find the longest palindromic substring of a given input string. If multiple longest palindromic substrings exist, the function may return any one of them.

-----Input-----
- s: String, the input string to search within

-----Output-----
- A String that is a palindrome and is a substring of s with maximal length among all palindromic substrings of s (ties allowed)

-----Note-----
- For the empty string, the result is "".
- For a single-character string, the result is the input itself.
- In tie cases (e.g., "babad"), the result can be either of the longest palindromes (e.g., "bab" or "aba").
