-----Description-----
Sort a list of natural numbers in ascending order using the heap sort algorithm, returning a list containing exactly the same elements as the input.

-----Input-----
- l: List Nat — the list of natural numbers to sort

-----Output-----
A List Nat that is the ascending-sorted version of l.

-----Note-----
The result preserves length and is a permutation of the input; sorting an already sorted result again yields the same list.
