-----Description-----
Compute the low median of a list of integers: after sorting, return the middle element for odd length, and the lower of the two middle elements for even length.

-----Input-----
- data: List Int, the input integer dataset (intended to be non-empty per the precondition)

-----Output-----
An Int equal to the low median of the sorted input list (returns 0 if the list is empty in the implementation).

-----Note-----
The algorithm sorts the data and then selects index n/2 for odd n, or n/2 - 1 for even n (0-based). A separate precondition specifies the list should be non-empty.
