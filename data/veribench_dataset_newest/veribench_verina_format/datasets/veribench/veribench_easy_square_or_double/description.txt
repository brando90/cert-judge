-----Description-----
Compute a value based on the parity of a natural number: square the number if it is even, otherwise double it.

-----Input-----
- n: Nat — the input natural number

-----Output-----
- Nat — returns n*n when n is even (n % 2 = 0), otherwise returns 2*n

-----Note-----
- The precondition is True, so all natural numbers are valid inputs.
- The result is always even.
