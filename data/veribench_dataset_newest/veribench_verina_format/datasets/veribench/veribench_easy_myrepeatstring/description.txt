-----Description-----
Return the string `s` repeated (concatenated) `n` times, where repeating 0 times yields the empty string.

-----Input-----
- s: A string to repeat
- n: A natural number indicating how many times to repeat `s`

-----Output-----
A string equal to `s ++ s ++ ... ++ s` (with `n` total copies of `s`); returns `""` when `n = 0`.

-----Note-----
The given precondition is `True`, so all `(s, n)` inputs are accepted. The file also contains an imperative version `myRepeatStringImp`, but the main function is `myRepeatString`.
