-----Description-----
Checks whether a natural number reads the same forwards and backwards (is a palindrome) by comparing its first and last digits recursively.

-----Input-----
- n: Nat — the natural number to check

-----Output-----
- Bool — true if n is a palindrome, false otherwise

-----Note-----
- 0 and all single-digit numbers are considered palindromes (return true).
- The implementation strips matching first/last digits and recurses on the remaining middle portion.
