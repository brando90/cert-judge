-----Description-----
Compute the length of the longest contiguous substring of the given string that contains no repeated characters.

-----Input-----
- s: String, the input string to analyze

-----Output-----
A natural number equal to the maximum length among all substrings of s whose characters are all distinct (returns 0 for the empty string).

-----Note-----
The provided implementation enumerates substrings (via list operations on characters) and selects the maximum length among those with unique characters.
