-----Description-----
Traverse an optional linked list and return the value stored in the last node. If the input is an empty optional node (representing a null pointer), return none.

-----Input-----
- lst: Option ListNode — the head of the linked list, or none to represent an empty/null list

-----Output-----
Option Nat — none if the list is empty; otherwise some lastValue where lastValue is the value in the final node

-----Note-----
The traversal follows next pointers until a node whose next is none is reached. The model treats an input of none as the null-pointer case and returns none.
