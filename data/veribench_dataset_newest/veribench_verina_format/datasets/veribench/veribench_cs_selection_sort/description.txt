-----Description-----
Sort a list of natural numbers in ascending order using the selection sort algorithm, returning a list that contains exactly the same elements as the input.

-----Input-----
- l: List Nat — the list of natural numbers to sort

-----Output-----
A List Nat that is the ascending-sorted version of the input list.

-----Note-----
The algorithm repeatedly extracts the minimum element and recurses on the remaining list; for an empty list it returns [].
