-----Description-----
Compute the longest string that is a prefix of every string in the input list.

-----Input-----
- strs: A list of strings.

-----Output-----
- Returns the longest common prefix shared by all strings in strs; returns the empty string "" if strs is empty or if there is no common prefix.

-----Note-----
- If strs has exactly one string, the result is that string.
- The implementation compares characters position-by-position up to the minimum string length.
