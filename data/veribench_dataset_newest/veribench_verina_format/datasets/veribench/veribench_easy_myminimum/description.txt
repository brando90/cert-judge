-----Description-----
Compute the minimum (smallest) natural number in a list. For the empty list, it returns 0 as a default.

-----Input-----
- xs: A list of natural numbers (List Nat)

-----Output-----
- A natural number equal to the smallest element of xs when xs is non-empty; returns 0 when xs is empty.

-----Note-----
- The intended use is for non-empty lists, but the implementation defines myMinList [] = 0.
- Implemented recursively using Nat.min between the head and the minimum of the tail.
