-----Description-----
Compute the longest common subsequence (LCS) of two lists, returning a list of elements that appears in both inputs in the same relative order and has maximal possible length.

-----Input-----
- l1: First list
- l2: Second list

-----Output-----
A list representing a longest common subsequence of l1 and l2.

-----Note-----
If multiple LCS solutions exist, the implementation deterministically chooses one based on recursive branching and a length comparison. Requires decidable equality on the element type.
