-----Description-----
Given a natural number n, return n itself if n is a perfect square; otherwise return n + 5.

-----Input-----
- n: Nat (a natural number)

-----Output-----
- A Nat equal to n when n is a perfect square, else equal to n + 5.

-----Note-----
- Perfect-square checking is done by testing k*k against n for k starting at 0 while k*k ≤ n.
- The result is always either n or n+5.
