-----Description-----
Compute the maximum element of a list of natural numbers. For an empty list, it returns 0 by definition (though the intended use is on non-empty lists).

-----Input-----
- xs: A list of natural numbers (List Nat)

-----Output-----
- A natural number equal to the largest element of xs when xs is non-empty; otherwise 0 when xs is empty

-----Note-----
- The stated precondition (Pre) requires xs to be non-empty (xs.length > 0), even though the function defines myMaxList [] = 0.
- The implementation is recursive using Nat.max.
