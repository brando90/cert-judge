-----Description-----
Removes all digit characters ('0' through '9') from the input string and returns the remaining characters in their original order.

-----Input-----
- s: String — the input string to process

-----Output-----
- A String equal to the input string with every digit character removed.

-----Note-----
- Non-digit characters (including letters, spaces, and punctuation) are preserved.
- The output length is never greater than the input length, and the result contains no digits.
