-----Description-----
Compute the natural-number power function: given a base `b` and exponent `e`, return `b` raised to the power `e` using the recursion `b^0 = 1` and `b^(e+1) = b * b^e`.

-----Input-----
- b: Nat, the base
- e: Nat, the exponent

-----Output-----
A Nat equal to b^e.

-----Note-----
Defined by primitive recursion on the exponent. The stated precondition is `True`, so all natural-number inputs are allowed.
