-----Description-----
Removes all lowercase letters 'a', 'b', 'c', 'd', and 'e' from the input string, preserving the order of the remaining characters.

-----Input-----
- s: A string (may be empty) to filter.

-----Output-----
A string equal to the input with every occurrence of lowercase 'a'–'e' removed.

-----Note-----
- Only lowercase letters are removed; uppercase 'A'–'E' are preserved.
- The output length is never greater than the input length.
- Applying the function twice yields the same result as applying it once.
