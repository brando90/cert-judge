-----Description-----
Replace every space character ' ' in the input string with an underscore '_' and leave all other characters unchanged.

-----Input-----
- s: String — the input string to transform

-----Output-----
- Returns a String of the same length as the input where each space is replaced by an underscore.

-----Note-----
- Non-space characters are preserved.
- The function is total: any string is accepted (precondition is True).
