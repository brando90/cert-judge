-----Description-----
Given a list of natural numbers, count how many elements are divisible by both 7 and 8 (equivalently, divisible by 56).

-----Input-----
- xs: a list of natural numbers (List Nat)

-----Output-----
- A natural number equal to the number of elements in xs that are divisible by both 7 and 8.

-----Note-----
- The function scans the list and increments a counter for each element n where n % 7 = 0 and n % 8 = 0.
- Precondition is True (all lists are valid inputs).
