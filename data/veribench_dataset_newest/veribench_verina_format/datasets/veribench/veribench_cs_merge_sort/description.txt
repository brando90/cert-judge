-----Description-----
Sort a list of natural numbers in nondecreasing order using the merge sort algorithm, returning a list with the same multiset of elements as the input.

-----Input-----
- l: List Nat — the list of natural numbers to sort

-----Output-----
A List Nat containing exactly the elements of the input list, sorted in ascending order.

-----Note-----
The precondition is always True (all lists are valid). The file also defines an imperative wrapper `mergeSortImp` that delegates to `mergeSort`, but the main function is `mergeSort`.
