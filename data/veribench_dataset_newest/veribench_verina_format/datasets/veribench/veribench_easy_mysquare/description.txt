-----Description-----
Compute the square of a natural number n (i.e., n²).

-----Input-----
- n: Nat — the natural number to be squared

-----Output-----
Returns n raised to the power 2 as a natural number.

-----Note-----
The precondition is True, so all natural numbers are accepted as inputs. The file also contains an imperative equivalent implementation (mySquareImp) and an equivalence theorem, but the main function is mySquare.
