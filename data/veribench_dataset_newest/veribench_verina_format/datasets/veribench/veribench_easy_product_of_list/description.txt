-----Description-----
Compute the product of all natural numbers in a list. The empty list returns 1 (the multiplicative identity).

-----Input-----
- xs: A list of natural numbers (List Nat)

-----Output-----
- A natural number equal to the product of all elements of xs (or 1 if xs is empty)

-----Note-----
- The computation is defined recursively: for x :: xs it returns x * myProductList xs.
- There is no input restriction (the precondition is True).
