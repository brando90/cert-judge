-----Description-----
Compute the length of the longest contiguous substring of the input string that forms a valid (well-balanced) parentheses sequence.

-----Input-----
- s: String, the input string (intended to contain parentheses characters)

-----Output-----
Returns a natural number equal to the maximum length among all valid-parentheses substrings of s (0 if none exist or if s is empty).

-----Note-----
The provided implementation enumerates substrings and checks validity; any string is accepted (no precondition restrictions).
