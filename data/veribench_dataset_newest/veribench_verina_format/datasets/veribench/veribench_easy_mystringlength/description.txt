-----Description-----
Compute the number of characters in a given string using the built-in string length.

-----Input-----
- s: String, the input string whose character count is to be computed

-----Output-----
A natural number (Nat) equal to the length of the input string.

-----Note-----
The precondition is trivially True, so all strings are accepted. The file also contains an imperative variant and an equivalence theorem, but the main function is the pure `myStringLength`.
