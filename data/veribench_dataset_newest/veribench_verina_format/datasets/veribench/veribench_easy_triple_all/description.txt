-----Description-----
Given a list of integers, return a new list where every element is multiplied by 3 (tripled), preserving the original order.

-----Input-----
- xs: A list of integers

-----Output-----
A list of integers of the same length as xs, where each element equals the corresponding input element multiplied by 3.

-----Note-----
The precondition is True, so all integer lists are accepted. The implementation uses a map over the list.
