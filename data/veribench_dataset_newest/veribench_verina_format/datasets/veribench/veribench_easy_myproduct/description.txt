-----Description-----
Compute the product of three natural numbers.

-----Input-----
- a: a natural number
- b: a natural number
- c: a natural number

-----Output-----
- Returns a * b * c as a natural number.

-----Note-----
- The precondition is True, so all natural-number inputs are accepted.
- An imperative variant (myProductImp) is defined in the file but is not the main function.
