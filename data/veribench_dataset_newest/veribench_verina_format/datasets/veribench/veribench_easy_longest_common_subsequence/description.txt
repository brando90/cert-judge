-----Description-----
Compute the longest common subsequence (LCS) between two input strings, returning a string whose characters appear in both inputs in the same relative order (not necessarily contiguously).

-----Input-----
- s1: First input string
- s2: Second input string

-----Output-----
A string representing the longest common subsequence of s1 and s2 (or "" if either input is empty or no common subsequence exists).

-----Note-----
The provided implementation uses a simplified recursive search over character lists; if either string is empty it immediately returns the empty string.
