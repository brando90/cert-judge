-----Description-----
Compute the factorial of a natural number using the standard recursive definition: 0! = 1 and (n+1)! = (n+1) * n!.

-----Input-----
- n: a natural number (Nat) whose factorial is to be computed

-----Output-----
- Returns n! as a natural number (Nat)

-----Note-----
- The precondition is True, so all natural numbers are accepted.
- An additional imperative version exists in the file, but the main function is the recursive `myFactorial`.
