-----Description-----
Sort a list of natural numbers in ascending order using insertion sort, returning a list that contains the same elements as the input.

-----Input-----
- l: List Nat — the list of natural numbers to sort

-----Output-----
- A List Nat containing the elements of l in nondecreasing (ascending) order.

-----Note-----
- The input is unrestricted (precondition is True).
- The result is intended to be sorted, a permutation of the input, length-preserving, and idempotent under repeated sorting.
