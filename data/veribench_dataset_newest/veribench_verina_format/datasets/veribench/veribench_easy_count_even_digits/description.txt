-----Description-----
Compute how many digits of a non-negative integer are even (0, 2, 4, 6, 8).

-----Input-----
- n: Nat — the non-negative integer whose decimal digits are examined

-----Output-----
Returns a Nat equal to the number of even decimal digits occurring in the base-10 representation of n (note: 0 counts as one even digit).

-----Note-----
The implementation converts n to a string and folds over its characters, incrementing a counter whenever the character is an even digit.
