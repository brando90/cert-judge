-----Description-----
Generate a deterministic hexadecimal token string of length 2*n by producing n fixed stub bytes and encoding them as lowercase hex.

-----Input-----
- n: Nat, the number of bytes of entropy to generate (deterministically stubbed)

-----Output-----
A String containing the hex encoding of the generated bytes; its length is intended to be 2 * n.

-----Note-----
The byte source is deterministic (replicates a constant byte 0xAB), so this is not a secure token generator; it is intended for benchmarking. Hex digits are lowercase.
