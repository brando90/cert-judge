-----Description-----
Sort a list of natural numbers in nondecreasing (ascending) order using bubble sort by repeatedly applying a bubbling pass up to the list length.

-----Input-----
- l: List Nat — the list of natural numbers to sort

-----Output-----
A List Nat containing the same elements as the input list, sorted in ascending order.

-----Note-----
The algorithm iterates bubble passes at most `length l` times and stops early if a pass makes no changes.
