-----Description-----
Filters a list of integers, returning a new list that contains only the elements that are even (divisible by 2), preserving the original order and multiplicity of those even elements.

-----Input-----
- xs: A list of integers

-----Output-----
- A list of integers consisting of exactly the even elements from xs, in the same order they appeared in xs

-----Note-----
- The precondition is True, so all integer lists are valid inputs.
- Odd elements are removed; duplicates of even elements are kept.
- Applying the function twice yields the same result as applying it once (idempotent).
