-----Description-----
Compute the high median of a list of integers: after sorting, return the middle element when the length is odd, and the larger of the two middle elements when the length is even.

-----Input-----
- data: List Int — a list of integers (intended to be non-empty by the precondition)

-----Output-----
An Int equal to the high median of the sorted input list (returns 0 on empty input in the implementation).

-----Note-----
The function sorts the list in nondecreasing order and returns the element at index (length / 2) (0-based). A separate precondition `Pre` states the list should be non-empty.
