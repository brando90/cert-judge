-----Description-----
Returns a new list containing the elements of the input list in reverse order.

-----Input-----
- xs: A list of natural numbers (List Nat) to be reversed

-----Output-----
A list of natural numbers with the same elements as xs but in reverse order.

-----Note-----
The precondition is True, so all lists of natural numbers are accepted. Unit tests include both the functional implementation (myReverse) and an imperative variant (myReverseImp).
