-----Description-----
Sort a list of natural numbers in ascending order using the quicksort algorithm, returning a list that contains exactly the same elements as the input.

-----Input-----
- xs: A list of natural numbers to be sorted.

-----Output-----
A list of natural numbers sorted in nondecreasing (ascending) order.

-----Note-----
The result is intended to be sorted, a permutation of the input, preserve length, and be idempotent (sorting twice yields the same result). The defined precondition is `True`, so all lists are valid inputs.
