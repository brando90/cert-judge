\begin{abstract}
% CS197 move 1: problem motivation (failure mode) -- AI-written formal specifications still need a human oracle; running tests or checking proofs cannot settle whether the specification is right.
Large language models judge whether AI-written formal specifications express the right guarantees, a question that running tests or checking proofs cannot settle.
% CS197 move 2: assumption (setup bit) -- reliability means agreement with human ratings, and that check is repeated for every new model, prompt, and domain.
Practitioners establish each judge's reliability through agreement with human ratings and repeat that check for every new model, prompt, and domain.
% CS197 move 3: contribution (bit flip) -- collect labels once; screen every later judge with falsifiable properties whose required score response is known by construction.
We propose collecting labels once, then screening new judges with falsifiable properties that specify how scores should respond to controlled edits.
% CS197 move 4a: instantiation (bit flip instantiation) -- Lean 4 specifications judged against gold; the four properties P1-P4. "target", not "test": the headline panels have no missing-specification ladders, so P3 is proposed but unmeasured there (Section 5.2).
Four properties target identity, bug monotonicity, missing-specification monotonicity, and stability for Lean~4 specifications.
% CS197 move 4b: instantiation (bit flip instantiation) -- the fixed equal-weight index TI_var and the plain-words reason for its multiplicative form (Equation eq:tivar).
A fixed equal-weight index, $\mathrm{TI}_{\mathrm{var}}$, combines bug monotonicity with two variance penalties multiplicatively, so no strong component can offset a weak one.
% CS197 move 5a: evaluation (setup and headline association) -- three families x eight configurations; "validation set" is the selection caveat (Sections 5.1 and 6), so no hedge clause here.
On a 72-pair validation set, the index tracks judge-level human agreement across three model families with eight configurations each.
% CS197 move 5b: evaluation (headline numbers) -- Codex panel Spearman 0.833 avg / 0.905 pass1 / 0.738 pass2; artifact experiments/archive/21_tmlr_submission/ci_provenance/headline_cis.json.
For the Codex panel, the Spearman correlation is 0.833 on averaged labels and 0.905 and 0.738 on the two rating passes.
% CS197 move 5c: evaluation (diagnostic result) -- the property report catches what human agreement misses: BAD_STRINGY rho 0.435 vs semantic prompts 0.365-0.466, 20/24 ladders with reversals (Table tab:codex_configs). The scalar's 0.940 stays in Section 5.3.
Bug-ladder checks expose a deliberately lexical judge that matches the semantic prompts' human agreement yet reverses on 20 of 24 ladders.
% CS197 move 6: implication (north star) -- Brando's approved closing (09-22-2026): "from X toward Y" vision, never a hedge; caveats live in move 5a and Section 6.
Judge validation thus moves from a per-judge annotation cost toward a one-time human panel plus automated, falsifiable checks that any new judge must pass.
\end{abstract}
