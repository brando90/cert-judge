\section*{Reproducibility Statement}
The anonymous supplement contains frozen score-level inputs and a standalone analysis script.
It reconstructs the fixed-index associations, local weight sensitivity, and recorded property diagnostics without new model inference.
The judge-level diagnostics of Appendix~\ref{app:judge-level-diagnostics} are exact recomputations from the same frozen vectors.
Appendix~\ref{app:judge-prompts} gives the prompt templates, exact model identifiers, input extraction, and repeat aggregation used for the main panels.
Appendix~\ref{app:index-definitions} specifies the indices, including normalization and numerical edge cases.
The supplement's manifest records input hashes, and its README identifies the reproduced outputs and exclusions.
It does not regenerate the original model calls, bootstrap intervals, human annotations, or every historical appendix analysis.
The original human-panel rubric text was not recovered, which limits exact replication of the annotation process.

\section*{Ethics Statement}
An author supplied the human ratings used for the headline validation analysis.
The study evaluates generated Lean code and formal statements, without personal data in the judged artifacts.
It makes no deployment claim and does not establish that screened judges can replace expert review in consequential settings.

\section*{Artificial Intelligence Use Statement}
LLMs generated candidate Lean artifacts and served as the judges under study.
Coding assistants helped implement experiments and analysis scripts, check and interpret results, and prepare figures.
They also assisted with methodological feedback, literature retrieval, manuscript drafting, and editing under author supervision.
The human ratings used for validation were supplied by a human annotator, not generated by these tools.
The authors are responsible for the manuscript's claims, citations, and interpretation of the recorded results.
