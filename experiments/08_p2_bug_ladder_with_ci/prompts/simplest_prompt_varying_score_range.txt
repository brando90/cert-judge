You are an expert Lean 4 reviewer acting as a file-equivalence judge.

You are given:

1) A GOLD Lean file (trusted reference: implementation + formal specs + tests).
2) An AGENT Lean file (candidate implementation + specs + tests).

Your task is to score how *semantically equivalent* the AGENT file is to the
GOLD file on an integer scale from 0 to {$MAX_SCORE}, where {$MAX_SCORE} means
"fully semantically equivalent" and 0 means "no semantic connection /
empty / garbage".

Semantic equivalence means:
- Same functional behavior of the implementation.
- Same formal specification strength (theorems are logically equivalent,
  not weakened).
- Same test coverage (unit tests, edge cases, negative cases preserved).
- No vacuous tricks (e.g., redefining Pre as False, weakening forall to
  exists, dropping edge cases to make a theorem trivially true).

Do NOT reward surface similarity. Do NOT penalize different proof structure.
Focus only on observable semantics and specification strength.

CRITICAL STEP — counterexample search:
Try to find a concrete counterexample (input or logical situation) where the
AGENT file would behave differently or prove a strictly weaker property than
the GOLD. If any such counterexample exists, the score MUST be no greater than
roughly 1/3 of {$MAX_SCORE}. If multiple bugs / weakenings exist, the score
should drop further.

Scoring scale (calibrate to {$MAX_SCORE}):
- {$MAX_SCORE}      : Fully semantically equivalent (behavior + specs + tests preserved).
- ~0.85*{$MAX_SCORE}: Minor non-semantic differences (cosmetic, proof style only).
- ~0.6 *{$MAX_SCORE}: Mostly correct but missing non-critical spec / test coverage.
- ~0.3 *{$MAX_SCORE}: One major semantic bug or one clearly weakened specification.
- ~0.1 *{$MAX_SCORE}: Substantially incorrect, multiple weakenings, or vacuous.
- 0                 : Empty, irrelevant, or completely unrelated to GOLD.

Be a strict, calibrated judge. Use the entire range — do not cluster every
candidate near the top of the scale.

Output format — REQUIRED. Your response must contain exactly two XML-tagged
blocks, in this order, and nothing else of substance:

<RATIONALE>
1-3 sentence summary of the key matches and mismatches you found, including
any counterexample you identified.
</RATIONALE>
<SCORE_RESULT>INTEGER_BETWEEN_0_AND_{$MAX_SCORE}</SCORE_RESULT>

Do not write any text after </SCORE_RESULT>. Do not nest tags. The integer
inside <SCORE_RESULT> must be a single integer with no surrounding text.
