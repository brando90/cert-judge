# Cost quote: paper's TI_var pipeline on Verina, no new human labels

**TLDR:** The minimal run (the paper's Codex-family judge panel, 24 Verina golds and 72 generated candidate–gold pairs, 3 repeats) is 5,184 judge calls, estimated at about $23.39 at API prices. The all-189-items version is 40,824 calls, about $184.22. Both also need 72 or 567 candidates generated by coding agents. These are planning estimates scaled from VeriBench prompt sizes; the exact quote comes from the real request manifest before any paid call.

## What is being priced

The paper's TI_var (variance-aware trust index) comes from one pipeline, `experiments/archive/04_veribench_validation/exp16_multi_judge_human_sets.py`, run with 3 repeats. Per judge configuration it scored 288 items (864 calls):

| Row type | VeriBench items | Needs human labels? |
|---|---:|---|
| Candidate–gold pairs (used for the repeat-stability terms) | 72 | No for TI_var; yes only for the human-agreement criterion |
| Rewrite probes (RENAME, REORDER, STYLE, ALPHA) on 24 golds | 96 | No |
| Bug ladder, levels L0–L4 on 24 golds | 120 | No |

The missing-specification ladder is not in this pipeline; the paper's P3 "weak" term is computed from the bug ladder (`exp17_property_human_analysis.py:99`).
The Verina run keeps the same row structure and replaces VeriBench golds and candidates with Verina ones.

## Quote

Judge panel: the paper's Codex family, i.e. `gpt-5.3-codex` × 4 prompts (P1_BASELINE, P4_CHECKLIST, P8_STRICT_B, BAD_STRINGY), `gpt-4o-mini` × 2 prompts (P8_STRICT_B, P4_CHECKLIST), plus the free controls `editdist_e1` and `random_r1`.

| **matched_24 (recommended)** | 24 | 72 | 864 | **5,184** | 1.47 M | **$23.39** ($22.69 Codex + $0.71 4o-mini) |
| full_189 | 189 | 567 | 6,804 | 40,824 | 11.59 M | $184.22 ($178.65 + $5.57) |

Assumptions (all from repo evidence, not guesses about Verina):

- Prompt sizes: VeriBench means, pairs 3.6 KB and property probes 0.9 KB (the gold is reduced to its last theorem block). Verina `task.lean` files are 1,097–7,613 B, median 1,769 B, so this is the right order of magnitude.
- Token bound: frozen PTI-v0 rule, input ≤ UTF-8 bytes + 128 tokens, output ≤ 256 tokens, no cache discount.
- Prices: the frozen repo config (`pti_v0_v4/frozen_config.json`, sources dated 08-21-2026): gpt-5.3-codex $1.75 / $14 per million input / output tokens; gpt-4o-mini $0.15 / $0.60.
- Adding the Claude family (claude-opus-4-7 × 4 prompts) or the Qwen family (self-hosted vLLM, graphics-processing-unit (GPU) time, no per-token cost) adds 3,456 calls per family for matched_24. Not priced here.

## Costs outside the judge calls

- **Candidate generation:** Verina releases no model-generated solutions, so 72 (or 567) candidates must be generated by coding agents. Run through subscription command-line tools (`codex exec`, `claude -p`), this has no per-token charge but uses subscription quota; one agentic attempt per cell with a fixed time/turn budget.
- **Lean:** the exp16 probe builders are text transforms with no compile step, so Verina's Lean v4.18 pin does not block the TI_var pipeline. Compiling generated candidates for the generation step needs a Verina Lean v4.18 project.

## The execution-path decision (Hard Rule 9)

The paper's judges were called through provider APIs (`02_neurips_reviews/utils/judge_caller.py`: OpenAI Responses API, Anthropic SDK), not command-line tools. Two options:

1. **Same API path as the paper (recommended).** The comparison is only clean if the judge configuration is identical, including decoding (temperature 1.0, 256 output tokens). Running the existing script loads `~/keys/*`, so it needs Brando's explicit approval of a dollar ceiling (this quote, re-derived exactly) before execution.
2. **Command-line path** (`cli-*` backends in the same `judge_caller.py`, lines 392–449). $0 marginal, but it changes the judge configuration, so VeriBench would have to be rescored through the same path as well (another 5,184 calls) to compare like with like.

Before any paid call, the run's first step builds the real request manifest and replaces this estimate with an exact per-request quote, as the frozen PTI-v0 quote did.

## Precondition to check

`gpt-5.3-codex` and `gpt-4o-mini` must still be served by the API. If either has been retired, the configuration cannot be reproduced and the design must change before any spend.
