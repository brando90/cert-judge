## Analyses and uncertainty

1. Inventory all existing v5 judge configurations (F, Z, per-fold rebuilt L in persona/C0 worlds, all-groups variants) and report exact overlap with the primary pool. 2. Property–criterion association across the 12 declared configurations, with individual Spearman, Pearson and Kendall statistics. Report finite configuration, base-model and provider-family counts. Two-way bootstrap: resample tasks jointly for properties and criterion, and resample base-model clusters with all their prompt/harness variants. Preserve original multiplicities. Use 10,000 draws, seed 47; report finite draw counts and percentile 95% intervals. With only three independent base models/two provider families, label population inference fragile; show leave-one-base-model and leave-one-provider-family-out separately, and never pretend 12 independent model families exist. Constant or insufficient-support correlations are undefined.
3. Selection utility: maximize each property, uniformly over exact ties; fixed H2 and random use exact expectations over eligible declared configurations. Measure expected selected Spearman, regret against the best hindsight judge on identical support, and paired gain versus H2 and random. Bootstrap tasks jointly and recompute property values and selected members in every draw; also show fixed-selection conditional intervals separately. Do not optimize a tolerance from outcomes. Missing property candidates remain in baseline/oracle denominators; a selector with no eligible candidate abstains.
4. Leave-one-agent-group-out: hold each G01–G13/G16/G17 criterion group out in turn; select by the frozen reference-only property without using any held-out outcomes. Since all groups share the same 50 references, state explicitly that this tests agent-group transfer conditional on known task references, not task transfer. Report every group and equal-group mean. Separately run five task folds assigned by SHA-256(task ID plus seed 47) rank, selecting on reference probes from four folds and evaluating candidate scores on the fifth; no criterion-driven property choice.
5. Leave-one-judge-family-out: remove each provider family as a sensitivity of selectors and association; report single-family degeneracy and missing eligible H2 comparators honestly. It does not train a new property or justify transfer to all unseen families.
6. Planning sensitivity for a +0.10 Spearman selection gain: use only completed sandbox measurements, and nested resampling of the paired task contributions/selection procedure. At fixed judge pool evaluate task counts 25, 50, 100, 200, 400; at observed subpool sizes 4, 6, 8, 12 use all feasible or seeded subset draws. Record simulation assumptions, Monte Carlo counts/intervals and effective independent model counts. To simulate a fixed +0.10 alternative, shift the centered bootstrap gain distribution, not raw scores or observed outcomes. Use the 97.5th percentile of the centered null as a one-sided rejection threshold and estimate rejection probability after shift. Target 80% power; this is agent-chosen planning sensitivity, not a validated human-study sample-size promise. Do not extrapolate independent judge families beyond those observed; return NOT_IDENTIFIABLE for a required number of new families without a defensible variance model.

All statistical headlines carry 95% intervals, counts and resampling units; `p-val=n/a` unless the named prespecified test is actually performed. Intervals condition on the existing simulated panel and frozen procedures; they omit new human-rater and model-family uncertainty. Never call these numbers judge–human agreement.

## Screening rule and execution gates

- This is a recommendation rule fixed by the helper, not an established universal threshold. A property is eligible for a 1–3-property recommendation only if ≥90% of declared judges have computable components, across-judge variability is nonzero, pooled property–criterion association is positive, and paired H2 selection gain is positive in both primary and common-family-excluded target views. Strong evidence requires the 95% lower bound for both gains >0. A +0.10 gain is the planning target, not a post hoc pass threshold.
- Recommend dropping from this sandbox shortlist if the property is constant, structurally invalid/uncomputable, or the 95% upper bound of H2 gain is ≤0 in either required view.
