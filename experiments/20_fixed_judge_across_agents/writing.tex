\paragraph{Cross-agent fixed-judge validation.}
We evaluate whether one frozen Lean theorem judge can score VeriBench solutions generated by multiple agent CLIs.
Each row records the exact agent CLI and observed model ID used to generate the candidate Lean artifact.
The primary acceptance criterion is that fixed-judge scores correlate with human judgments for each agent row.
A trust-index trend across agent rows requires an explicit agent-conditioned trust-index definition; the existing cert index is per judge and is constant under one frozen judge.
We will report Pearson, Spearman, and Kendall correlations for the per-agent judge-human table, and we will not claim the result until the tables in \texttt{experiments/20\_fixed\_judge\_across\_agents/results.md} are populated from real runs.
